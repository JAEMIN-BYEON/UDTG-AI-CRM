# 브랜드 로고 폴더

화주사 로고 이미지(PNG 권장, 배경 투명)를 여기에 넣으면 견적서 우측 상단에 자동 삽입된다.

- 파일명은 `brand_colors.json` 의 `logo` 값 또는 견적 JSON의 `brand_logo` 값과 일치시킬 것
  - 예: `cj_daehantongwoon.png`, `samsung_welstory.png`
- 권장 크기: 높이 100~200px, 가로 비율 자유
- **파일이 없으면** 브랜드명이 대표 컬러 로고타입으로 자동 렌더링된다 (오류 아님)

> 샌드박스는 외부 이미지 다운로드가 차단되어 있어 로고 URL 링크는 PDF에서 표시되지 않는다.
> 로고는 반드시 이 폴더에 파일로 보관해야 한다. 한 번 넣어두면 이후 모든 견적서에서 재사용된다.
